03Approach

I learn the platform before I write the feature. Most of this site began with a machine or a codebase I did not understand and ended with software running on it. The PlayStation 2 is the clearest case: a 2000-era console with 32 MB of main memory, a separate audio processor, and an I/O processor that has to be told which drivers to load.

I also write down what has and has not been verified. The DAW's README separates "builds", "runs in an emulator" and "confirmed on real hardware", and says plainly that the last column is still empty. I have tried to hold this whole portfolio to the same standard.
